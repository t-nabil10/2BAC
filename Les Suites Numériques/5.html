V. Limite d'une suite

Définition : On dit que la suite \((u_n)\) converge vers \(L\) (ou admet pour limite \(L\)) si les termes \(u_n\) s'approchent de \(L\) lorsque \(n\) tend vers \(+\infty\). On note : \[ \lim\limits_{n \to +\infty} u_n = L \]
Définition : On dit que \((u_n)\) tend vers \(+\infty\) si les termes deviennent aussi grands que l'on veut. On note : \[ \lim\limits_{n \to +\infty} u_n = +\infty \]

1) Limites de suites usuelles

Suite \((u_n)\)Limite en \(+\infty\)
\(u_n = k\) (constante)\(k\)
\(u_n = n\)\(+\infty\)
\(u_n = n^2\)\(+\infty\)
\(u_n = \dfrac{1}{n}\)\(0\)
\(u_n = \dfrac{1}{n^2}\)\(0\)
\(u_n = q^n\) avec \(|q| < 1\)\(0\)
\(u_n = q^n\) avec \(q > 1\)\(+\infty\)

2) Opérations sur les limites

Les mêmes règles que pour les limites de fonctions s'appliquent : somme, produit, quotient, composition.

Formes indéterminées à connaître :
  • \(+\infty - \infty\)
  • \(0 \times \infty\)
  • \(\dfrac{\infty}{\infty}\)
  • \(\dfrac{0}{0}\)
Dans ces cas, il faut transformer l'expression (factoriser par le terme dominant, multiplier par le conjugué, etc.).
Exemple 6 : Calculer \(\lim\limits_{n \to +\infty} \dfrac{2n^2 + 3n - 1}{n^2 + 5}\).
On factorise par \(n^2\) au numérateur et au dénominateur : \(\dfrac{2n^2 + 3n - 1}{n^2 + 5} = \dfrac{n^2\left(2 + \dfrac{3}{n} - \dfrac{1}{n^2}\right)}{n^2\left(1 + \dfrac{5}{n^2}\right)} = \dfrac{2 + \dfrac{3}{n} - \dfrac{1}{n^2}}{1 + \dfrac{5}{n^2}}\) Or \(\lim\limits_{n \to +\infty} \dfrac{3}{n} = 0\), \(\lim\limits_{n \to +\infty} \dfrac{1}{n^2} = 0\), \(\lim\limits_{n \to +\infty} \dfrac{5}{n^2} = 0\). Donc la limite vaut \(\dfrac{2 + 0 - 0}{1 + 0} = 2\). lim = 2
Exemple 7 : Calculer \(\lim\limits_{n \to +\infty} \left(\sqrt{n + 1} - \sqrt{n}\right)\).
On multiplie par le conjugué : \(\sqrt{n+1} - \sqrt{n} = \dfrac{(\sqrt{n+1} - \sqrt{n})(\sqrt{n+1} + \sqrt{n})}{\sqrt{n+1} + \sqrt{n}} = \dfrac{(n+1) - n}{\sqrt{n+1} + \sqrt{n}} = \dfrac{1}{\sqrt{n+1} + \sqrt{n}}\) Or \(\lim\limits_{n \to +\infty} (\sqrt{n+1} + \sqrt{n}) = +\infty\), donc \(\lim\limits_{n \to +\infty} \dfrac{1}{\sqrt{n+1} + \sqrt{n}} = 0\). lim = 0
