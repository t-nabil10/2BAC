Les Primitives 2ème Bac Sciences Économiques — Maroc

I. Définition

Définition : Soit \(f\) une fonction définie sur un intervalle \(I\).

On appelle primitive de \(f\) sur \(I\) toute fonction \(F\) dérivable sur \(I\) telle que : \[ F'(x) = f(x) \quad \text{pour tout } x \in I \]
Une primitive de \(f\) est une fonction \(F\) dont la dérivée est \(f\). Autrement dit, \(F\) est « l'antidérivée » de \(f\).
Exemple 1 : Vérifier que \(F(x) = x^2\) est une primitive de \(f(x) = 2x\) sur \(\mathbb{R}\).
On dérive \(F\) : \(F'(x) = (x^2)' = 2x = f(x)\). Donc \(F\) est bien une primitive de \(f\) sur \(\mathbb{R}\). F(x) = x² est une primitive de f(x) = 2x
Exemple 2 : Vérifier que \(G(x) = x^2 + 5\) est aussi une primitive de \(f(x) = 2x\).
On dérive \(G\) : \(G'(x) = (x^2 + 5)' = 2x + 0 = 2x = f(x)\). Donc \(G\) est aussi une primitive de \(f\). G(x) = x² + 5 est aussi une primitive de f

II. Infinité des primitives

Théorème : Si \(F\) est une primitive de \(f\) sur un intervalle \(I\), alors toutes les primitives de \(f\) sur \(I\) sont de la forme : \[ G(x) = F(x) + k \quad \text{où } k \in \mathbb{R} \]
Deux primitives d'une même fonction diffèrent d'une constante. Il y a donc une infinité de primitives pour une fonction donnée.
\[ \text{Primitives de } f : \quad F(x) + k \quad (k \in \mathbb{R}) \]
💡 Conséquence : Pour déterminer la primitive qui prend une valeur donnée en un point, on utilise la condition initiale pour trouver \(k\).
Exemple 3 : Soit \(f(x) = 2x\). Déterminer la primitive \(F\) de \(f\) telle que \(F(1) = 3\).
Les primitives de \(f\) sont de la forme \(F(x) = x^2 + k\). On utilise la condition \(F(1) = 3\) : \(1^2 + k = 3 \Rightarrow 1 + k = 3 \Rightarrow k = 2\). Donc \(F(x) = x^2 + 2\). F(x) = x² + 2

IV. Primitives de fonctions composées

Formules à connaître : si \(u\) est une fonction dérivable sur \(I\) :
  • Primitive de \(u' \cdot u^n\) (\(n \neq -1\)) : \(\dfrac{u^{n+1}}{n+1} + C\)
  • Primitive de \(\dfrac{u'}{u^2}\) : \(-\dfrac{1}{u} + C\)
  • Primitive de \(\dfrac{u'}{u}\) (avec \(u > 0\)) : \(\ln(u) + C\)
  • Primitive de \(\dfrac{u'}{\sqrt{u}}\) (avec \(u > 0\)) : \(2\sqrt{u} + C\)
  • Primitive de \(u' \cdot e^u\) : \(e^u + C\)
Pour reconnaître une forme composée, on repère la présence de \(u'\) (dérivée de l'expression intérieure) à côté de \(u\).
Exemple 4 : Déterminer une primitive de \(f(x) = (2x + 1)^3\).
On pose \(u(x) = 2x + 1\), donc \(u'(x) = 2\). On écrit \(f(x) = \dfrac{1}{2} \cdot 2 \cdot (2x+1)^3 = \dfrac{1}{2} u' u^3\). Une primitive de \(u' u^3\) est \(\dfrac{u^4}{4}\). Donc une primitive de \(f\) est \(F(x) = \dfrac{1}{2} \cdot \dfrac{(2x+1)^4}{4} = \dfrac{(2x+1)^4}{8}\). F(x) = (2x + 1)⁴ / 8
Exemple 5 : Déterminer une primitive de \(g(x) = \dfrac{2x}{x^2 + 1}\).
On pose \(u(x) = x^2 + 1\), donc \(u'(x) = 2x\). On a \(g(x) = \dfrac{u'}{u}\) avec \(u > 0\). Une primitive est donc \(G(x) = \ln(u) = \ln(x^2 + 1)\). G(x) = ln(x² + 1)
Exemple 6 : Déterminer une primitive de \(h(x) = \dfrac{3}{(3x + 1)^2}\).
On pose \(u(x) = 3x + 1\), donc \(u'(x) = 3\). On a \(h(x) = \dfrac{u'}{u^2}\). Une primitive de \(\dfrac{u'}{u^2}\) est \(-\dfrac{1}{u}\). Donc \(H(x) = -\dfrac{1}{3x + 1}\). H(x) = −1 / (3x + 1)

💡 Attention : il n'y a pas de formule générale pour une primitive d'un produit ou d'un quotient. Il faut souvent transformer l'expression ou reconnaître une forme composée.

VI. Application économique

Les primitives sont utilisées en économie pour :

  • Retrouver le coût total à partir du coût marginal : \(C(x) = \int C_m(x) \, dx\) (primitive).
  • Retrouver la recette totale à partir de la recette marginale : \(R(x)\) est une primitive de \(R_m(x)\).
  • Calculer le surplus du consommateur ou du producteur.
  • Déterminer une fonction de profit à partir de la fonction de profit marginal.
Exemple 7 (application économique) : Le coût marginal d'une entreprise est donné par \(C_m(x) = 2x + 5\) (en DH par unité).
Sachant que le coût fixe est \(C(0) = 100\) DH, déterminer le coût total \(C(x)\).
Le coût total \(C\) est une primitive de \(C_m\) : \(C(x) = x^2 + 5x + k\). On utilise la condition \(C(0) = 100\) : \(0^2 + 5(0) + k = 100 \Rightarrow k = 100\). Donc \(C(x) = x^2 + 5x + 100\). C(x) = x² + 5x + 100

Résumé général

  • Primitive : \(F\) est une primitive de \(f\) si \(F' = f\).
  • Infinité : les primitives de \(f\) sont \(F(x) + k\) où \(k \in \mathbb{R}\).
  • Primitive de \(x^n\) : \(\dfrac{x^{n+1}}{n+1} + C\) (pour \(n \neq -1\)).
  • Primitive de \(\dfrac{1}{x}\) : \(\ln|x| + C\).
  • Formes composées : \(u'u^n\), \(\dfrac{u'}{u}\), \(\dfrac{u'}{u^2}\).
  • Condition initiale : \(F(a) = b\) permet de trouver la constante \(k\).
  • Application économique : le coût total est une primitive du coût marginal ; la recette totale est une primitive de la recette marginale.
💡 Conseils pour le Bac :
  • Pour vérifier une primitive, il suffit de la dériver : on doit retrouver \(f\).
  • N'oublie pas le \(+\, C\) quand on demande « les primitives » (et pas « une primitive »).
  • Pour les formes composées, repère la présence de \(u'\) à côté de \(u\).
  • Si \(u'\) n'est pas exactement présent, ajuste avec un coefficient multiplicateur.
  • Pour déterminer \(k\), utilise la condition initiale \(F(a) = b\) et résous l'équation.
  • En économie, le coût fixe \(C(0)\) permet de déterminer la constante d'intégration.
