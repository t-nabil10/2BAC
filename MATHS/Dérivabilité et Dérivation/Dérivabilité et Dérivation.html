Dérivabilité et Dérivation 2ème Bac Sciences Économiques — Maroc

I. Nombre dérivé en un point

Définition : Soit \(f\) une fonction définie sur un intervalle ouvert contenant \(a\).

On dit que \(f\) est dérivable en \(a\) si le taux d'accroissement admet une limite finie lorsque \(h\) tend vers \(0\) : \[ \lim\limits_{h \to 0} \dfrac{f(a+h) - f(a)}{h} = L \] Ce réel \(L\) est appelé nombre dérivé de \(f\) en \(a\) et on note \(f'(a) = L\).

On peut aussi écrire de façon équivalente :

\[ f'(a) = \lim\limits_{x \to a} \dfrac{f(x) - f(a)}{x - a} \]
📈 Interprétation graphique : \(f'(a)\) est le coefficient directeur de la tangente à la courbe de \(f\) au point d'abscisse \(a\).

II. Équation de la tangente

Théorème : Si \(f\) est dérivable en \(a\), alors la courbe de \(f\) admet une tangente au point d'abscisse \(a\), d'équation : \[ y = f'(a)(x - a) + f(a) \]
Exemple 1 : Soit \(f(x) = x^2\).
1) Calculer \(f'(2)\) à l'aide de la définition.
2) Donner l'équation de la tangente à la courbe de \(f\) au point d'abscisse \(2\).
1) On calcule le taux d'accroissement : \(\dfrac{f(2+h) - f(2)}{h} = \dfrac{(2+h)^2 - 4}{h} = \dfrac{4 + 4h + h^2 - 4}{h} = \dfrac{4h + h^2}{h} = 4 + h\) Puis on passe à la limite : \(\lim\limits_{h \to 0} (4 + h) = 4\). Donc \(f'(2) = 4\). 2) La tangente a pour équation : \(y = f'(2)(x - 2) + f(2) = 4(x - 2) + 4 = 4x - 8 + 4 = 4x - 4\) f'(2) = 4 · Tangente : y = 4x − 4

III. Dérivabilité et continuité

Théorème : Si \(f\) est dérivable en \(a\), alors \(f\) est continue en \(a\).

La réciproque est fausse : une fonction peut être continue en \(a\) sans être dérivable en \(a\). (Exemple : \(f(x) = |x|\) en \(0\).)
💡 À retenir : Dérivable ⟹ Continue. Mais Continue ⇏ Dérivable.

IV. Fonction dérivée

Définition : Si \(f\) est dérivable en tout point d'un intervalle \(I\), on appelle fonction dérivée de \(f\) sur \(I\) la fonction \(f'\) qui à tout \(x \in I\) associe \(f'(x)\).

2) Opérations sur les dérivées

FonctionDérivéeCondition

💡 Formules de la composée à connaître :
  • \(\left(\sqrt{u}\right)' = \dfrac{u'}{2\sqrt{u}}\)
  • \(\left(\dfrac{1}{u}\right)' = -\dfrac{u'}{u^2}\)
  • \(\left(u^n\right)' = n\,u'\,u^{n-1}\)
  • \(\left(\ln u\right)' = \dfrac{u'}{u}\) (avec \(u > 0\))

V. Calcul de dérivées — exemples

Exemple 2 : Calculer la dérivée de \(f(x) = 3x^3 - 5x^2 + 2x - 7\).
On dérive terme à terme : \((3x^3)' = 9x^2\) \((-5x^2)' = -10x\) \((2x)' = 2\) \((-7)' = 0\) f'(x) = 9x² − 10x + 2
Exemple 3 : Calculer la dérivée de \(g(x) = \dfrac{x + 1}{x - 2}\).
On utilise la formule \(\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}\) avec \(u = x+1\) et \(v = x-2\). \(u' = 1\) et \(v' = 1\). \(g'(x) = \dfrac{1 \cdot (x-2) - (x+1) \cdot 1}{(x-2)^2} = \dfrac{x - 2 - x - 1}{(x-2)^2} = \dfrac{-3}{(x-2)^2}\) g'(x) = −3 / (x−2)²
Exemple 4 : Calculer la dérivée de \(h(x) = \sqrt{x^2 + 1}\).
On utilise la formule \(\left(\sqrt{u}\right)' = \dfrac{u'}{2\sqrt{u}}\) avec \(u = x^2 + 1\). \(u' = 2x\). \(h'(x) = \dfrac{2x}{2\sqrt{x^2 + 1}} = \dfrac{x}{\sqrt{x^2 + 1}}\) h'(x) = x / √(x² + 1)

VI. Signe de la dérivée et sens de variation

Théorème fondamental : Soit \(f\) dérivable sur un intervalle \(I\).
  • Si \(f'(x) > 0\) sur \(I\), alors \(f\) est strictement croissante sur \(I\).
  • Si \(f'(x) < 0\) sur \(I\), alors \(f\) est strictement décroissante sur \(I\).
  • Si \(f'(x) = 0\) sur \(I\), alors \(f\) est constante sur \(I\).

Méthode d'étude des variations

  1. Calculer \(f'(x)\).
  2. Étudier le signe de \(f'(x)\) (résoudre \(f'(x) = 0\), faire un tableau de signes).
  3. Dresser le tableau de variations de \(f\).
Exemple 5 (type Bac) : Soit \(f(x) = x^3 - 3x + 1\).
1) Calculer \(f'(x)\).
2) Étudier le signe de \(f'(x)\) et dresser le tableau de variations de \(f\).
1) \(f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x-1)(x+1)\). 2) On résout \(f'(x) = 0\) : \(x = -1\) ou \(x = 1\). Signe de \(f'(x)\) : • Sur \(]-\infty, -1[\) : \(f'(x) > 0\) → \(f\) croissante • Sur \(]-1, 1[\) : \(f'(x) < 0\) → \(f\) décroissante • Sur \(]1, +\infty[\) : \(f'(x) > 0\) → \(f\) croissante Valeurs aux bornes des intervalles : \(f(-1) = (-1)^3 - 3(-1) + 1 = -1 + 3 + 1 = 3\) (maximum local) \(f(1) = 1^3 - 3(1) + 1 = 1 - 3 + 1 = -1\) (minimum local) f croissante sur ]−∞,−1[ ∪ ]1,+∞[ ; décroissante sur ]−1,1[

VII. Extremums locaux

Définition : \(f\) admet un maximum local en \(a\) s'il existe un intervalle ouvert contenant \(a\) tel que \(f(x) \leq f(a)\) pour tout \(x\) de cet intervalle.

\(f\) admet un minimum local en \(a\) si \(f(x) \geq f(a)\) sur un intervalle ouvert contenant \(a\).
Théorème : Si \(f\) est dérivable en \(a\) et admet un extremum local en \(a\), alors \(f'(a) = 0\).

Attention : la réciproque est fausse (ex. \(f(x) = x^3\) en \(0\) : \(f'(0) = 0\) mais pas d'extremum).
💡 Condition suffisante : Si \(f'(x)\) change de signe en \(a\) :
  • de \(+\) à \(-\) → \(f(a)\) est un maximum local ;
  • de \(-\) à \(+\) → \(f(a)\) est un minimum local.

VIII. Application économique

En Sciences Économiques, la dérivée est utilisée pour :

  • Coût marginal : \(C_m(x) = C'(x)\) où \(C(x)\) est le coût total de production de \(x\) unités.
  • Recette marginale : \(R_m(x) = R'(x)\) où \(R(x)\) est la recette totale.
  • Profit maximal : le profit \(B(x) = R(x) - C(x)\) est maximal lorsque \(B'(x) = 0\), c'est-à-dire \(R'(x) = C'(x)\).
  • Seuil de rentabilité : valeur de \(x\) pour laquelle \(B(x) = 0\).
Exemple 6 (application économique) : Une entreprise produit \(x\) unités d'un bien (\(x \in [0, 50]\)).
Le coût total est \(C(x) = x^2 + 10x + 100\) (en dirhams) et la recette est \(R(x) = 30x\).
1) Calculer le profit \(B(x) = R(x) - C(x)\).
2) Déterminer la quantité \(x\) qui maximise le profit.
1) \(B(x) = 30x - (x^2 + 10x + 100) = -x^2 + 20x - 100\). 2) On calcule \(B'(x) = -2x + 20\). On résout \(B'(x) = 0\) : \(-2x + 20 = 0 \Rightarrow x = 10\). \(B'(x) > 0\) pour \(x < 10\) et \(B'(x) < 0\) pour \(x > 10\). Donc \(B\) admet un maximum en \(x = 10\). \(B(10) = -100 + 200 - 100 = 0\). Profit maximal pour x = 10 unités

Résumé général

  • Nombre dérivé : \(f'(a) = \lim\limits_{h \to 0} \dfrac{f(a+h)-f(a)}{h}\) = coefficient directeur de la tangente.
  • Tangente : \(y = f'(a)(x-a) + f(a)\).
  • Dérivable ⟹ continue (mais pas l'inverse).
  • Dérivées usuelles : \((x^n)' = nx^{n-1}\), \(\left(\dfrac{1}{x}\right)' = -\dfrac{1}{x^2}\), \((\sqrt{x})' = \dfrac{1}{2\sqrt{x}}\), \((\ln x)' = \dfrac{1}{x}\).
  • Opérations : somme, produit, quotient, composée.
  • Signe de \(f'\) : \(f' > 0\) → \(f\) croissante ; \(f' < 0\) → \(f\) décroissante.
  • Extremum local : \(f'(a) = 0\) avec changement de signe.
  • Application économique : coût marginal, recette marginale, profit maximal (\(R'(x) = C'(x)\)).
💡 Conseils pour le Bac :
  • Vérifie toujours le domaine de dérivabilité avant de dériver (surtout pour \(\sqrt{}\) et \(\ln\)).
  • Pour un quotient, utilise la formule \(\dfrac{u'v - uv'}{v^2}\) sans oublier le signe \(-\).
  • Dresse un tableau de signes de \(f'(x)\) pour déduire les variations.
  • Pour un extremum, vérifie le changement de signe de \(f'\), pas seulement \(f'(a) = 0\).
  • En économie, le profit est maximal quand la recette marginale égale le coût marginal : \(R'(x) = C'(x)\).
