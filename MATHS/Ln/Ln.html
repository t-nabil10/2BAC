Fonction Logarithme Népérien 2ème Bac Sciences Économiques — Maroc

I. Définition et domaine

Définition : La fonction logarithme népérien, notée \(\ln\), est définie sur \(]0, +\infty[\) par : \[ \ln(x) = \int_1^x \dfrac{1}{t} \, dt \quad \text{pour } x > 0 \] C'est la fonction réciproque de la fonction exponentielle \(x \mapsto e^x\).
\[ \ln(1) = 0 \quad \text{et} \quad \ln(e) = 1 \]
La courbe \(C_{\ln}\) est définie uniquement pour \(x > 0\) : elle ne traverse jamais l'axe des ordonnées et reste à droite de l'axe \((Oy)\).

II. Propriétés algébriques

Pour tous réels \(a > 0\) et \(b > 0\), et pour tout entier \(n\) :
  • \(\ln(ab) = \ln(a) + \ln(b)\)
  • \(\ln\left(\dfrac{a}{b}\right) = \ln(a) - \ln(b)\)
  • \(\ln\left(\dfrac{1}{b}\right) = -\ln(b)\)
  • \(\ln(a^n) = n \ln(a)\)
  • \(\ln(\sqrt{a}) = \dfrac{1}{2} \ln(a)\)
💡 Attention : \(\ln(a + b) \neq \ln(a) + \ln(b)\) ! Le logarithme transforme les produits en sommes, pas les sommes en sommes.
Exemple 1 : Simplifier \(A = \ln(8) - \ln(2) + \ln(4)\).
\(A = \ln(8) - \ln(2) + \ln(4) = \ln\left(\dfrac{8 \times 4}{2}\right)\) \(= \ln\left(\dfrac{32}{2}\right) = \ln(16)\) Or \(16 = 2^4\), donc \(A = \ln(2^4) = 4\ln(2)\). A = 4 ln(2)
Exemple 2 : Écrire \(B = \ln(9) + 2\ln(3) - \ln(27)\) sous la forme \(k\ln(3)\).
\(\ln(9) = \ln(3^2) = 2\ln(3)\) \(\ln(27) = \ln(3^3) = 3\ln(3)\) Donc \(B = 2\ln(3) + 2\ln(3) - 3\ln(3) = \ln(3)\). B = ln(3)

III. Étude de la fonction \(\ln\)

1) Limites aux bornes

\[ \lim\limits_{x \to 0^+} \ln(x) = -\infty \quad \text{et} \quad \lim\limits_{x \to +\infty} \ln(x) = +\infty \]
\(C_{\ln}\) admet une asymptote verticale d'équation \(x = 0\) (axe des ordonnées).
Courbe de \(\ln\) : asymptote verticale \(x = 0\), concave, passe par \((1 ; 0)\) et \((e ; 1)\).

2) Dérivée et variations

\[ (\ln x)' = \dfrac{1}{x} \quad \text{pour } x > 0 \]

Comme \(\dfrac{1}{x} > 0\) pour tout \(x > 0\), la fonction \(\ln\) est strictement croissante sur \(]0, +\infty[\).

\(x\)\(0\)\(+\infty\)
\((\ln x)'\)\(+\)
\(\ln x\)\(-\infty\)↗\(+\infty\)
\(C_{\ln}\) est strictement croissante sur \(]0, +\infty[\) : elle part de \(-\infty\) (en \(0^+\)) et monte vers \(+\infty\).

IV. Limites usuelles et croissances comparées

Limites à connaître :
  • \(\lim\limits_{x \to 0^+} x\ln(x) = 0\)
  • \(\lim\limits_{x \to +\infty} \dfrac{\ln(x)}{x} = 0\)
  • \(\lim\limits_{x \to +\infty} \dfrac{\ln(x)}{x^n} = 0\) (pour \(n \geq 1\))
  • \(\lim\limits_{x \to 0^+} \ln(x) = -\infty\)
💡 Règle de croissance comparée : à l'infini, \(x^n\) croît plus vite que \(\ln(x)\). Donc \(\dfrac{\ln(x)}{x^n} \to 0\). Et en \(0^+\), \(x\ln(x) \to 0\).
Exemple 3 : Calculer \(\lim\limits_{x \to +\infty} \dfrac{\ln(x) + 1}{x}\).
On sépare : \(\dfrac{\ln(x) + 1}{x} = \dfrac{\ln(x)}{x} + \dfrac{1}{x}\). Or \(\lim\limits_{x \to +\infty} \dfrac{\ln(x)}{x} = 0\) et \(\lim\limits_{x \to +\infty} \dfrac{1}{x} = 0\). lim = 0
Exemple 4 : Calculer \(\lim\limits_{x \to 0^+} x\ln(x)\).
C'est une forme indéterminée \(0 \times (-\infty)\). D'après les limites usuelles, \(\lim\limits_{x \to 0^+} x\ln(x) = 0\). lim = 0

V. Dérivée de fonctions composées

Formules à connaître :
  • \((\ln u)' = \dfrac{u'}{u}\) (avec \(u > 0\))
  • \((\ln(ax + b))' = \dfrac{a}{ax + b}\) (avec \(ax + b > 0\))
  • \((\ln(x^2))' = \dfrac{2}{x}\) (pour \(x \neq 0\))
Exemple 5 : Calculer la dérivée de \(f(x) = \ln(x^2 + 1)\).
On pose \(u(x) = x^2 + 1 > 0\) pour tout \(x\). \(u'(x) = 2x\). \(f'(x) = \dfrac{u'}{u} = \dfrac{2x}{x^2 + 1}\). f'(x) = 2x / (x² + 1)
Exemple 6 : Calculer la dérivée de \(g(x) = \ln\left(\dfrac{x + 1}{x - 1}\right)\) (pour \(x > 1\)).
On peut écrire \(g(x) = \ln(x + 1) - \ln(x - 1)\). \(g'(x) = \dfrac{1}{x + 1} - \dfrac{1}{x - 1}\). \(= \dfrac{(x - 1) - (x + 1)}{(x + 1)(x - 1)} = \dfrac{-2}{x^2 - 1}\). g'(x) = −2 / (x² − 1)

VI. Équations et inéquations avec \(\ln\)

Propriétés :
  • \(\ln(a) = \ln(b) \iff a = b\) (avec \(a > 0, b > 0\))
  • \(\ln(a) > \ln(b) \iff a > b\) (car \(\ln\) est strictement croissante)
  • \(\ln(x) = k \iff x = e^k\)
Exemple 7 : Résoudre l'équation \(\ln(2x - 1) = 0\).
Domaine : \(2x - 1 > 0 \Rightarrow x > \dfrac{1}{2}\). \(\ln(2x - 1) = 0 \iff 2x - 1 = e^0 = 1\). \(2x = 2 \Rightarrow x = 1\). Or \(1 > \dfrac{1}{2}\), donc \(x = 1\) est solution. S = {1}
Exemple 8 : Résoudre l'inéquation \(\ln(x) > 1\).
Domaine : \(x > 0\). \(\ln(x) > 1 \iff x > e^1 = e\). S = ]e, +∞[

VII. Concavité de \(\ln\)

\[ (\ln x)'' = -\dfrac{1}{x^2} < 0 \quad \text{pour tout } x > 0 \]
La courbe \(C_{\ln}\) est concave sur \(]0, +\infty[\) (elle est en dessous de ses tangentes). Elle ne présente pas de point d'inflexion.
La courbe de \(\ln\) est concave : elle se situe en dessous de ses tangentes.

VIII. Application économique

La fonction logarithme est utilisée en économie pour :

  • Modéliser des croissances ralenties (saturation d'un marché, utilité marginale décroissante).
  • Linéariser des relations multiplicatives : \(\ln(AB) = \ln A + \ln B\).
  • Calculer des taux de croissance et des élasticités.
  • Étudier des fonctions d'utilité de type \(U(x) = \ln(x)\) (utilité concave).
  • Modéliser des coûts ou des rendements avec des fonctions \(\ln\).
Exemple 9 (application économique) : Une fonction d'utilité est donnée par \(U(x) = \ln(x)\) pour \(x > 0\) (x = quantité consommée).
1) Calculer \(U'(x)\).
2) Étudier la concavité de \(U\) et interpréter économiquement.
1) \(U'(x) = \dfrac{1}{x} > 0\) pour tout \(x > 0\). Donc \(U\) est strictement croissante : plus on consomme, plus l'utilité augmente. 2) \(U''(x) = -\dfrac{1}{x^2} < 0\). Donc \(U\) est concave : l'utilité marginale \(U'(x) = \dfrac{1}{x}\) diminue quand \(x\) augmente. Interprétation : chaque unité supplémentaire apporte moins de satisfaction (loi de l'utilité marginale décroissante). U' = 1/x > 0 · U'' = −1/x² < 0 · utilité marginale décroissante

Résumé général

  • Domaine : \(\ln\) est définie sur \(]0, +\infty[\).
  • Valeurs clés : \(\ln(1) = 0\), \(\ln(e) = 1\).
  • Propriétés : \(\ln(ab) = \ln a + \ln b\), \(\ln\left(\dfrac{a}{b}\right) = \ln a - \ln b\), \(\ln(a^n) = n\ln a\).
  • Dérivée : \((\ln x)' = \dfrac{1}{x} > 0\) → \(\ln\) strictement croissante.
  • Limites : \(\lim\limits_{x \to 0^+} \ln x = -\infty\) (asymptote \(x = 0\)) ; \(\lim\limits_{x \to +\infty} \ln x = +\infty\).
  • Croissance comparée : \(\lim\limits_{x \to +\infty} \dfrac{\ln x}{x} = 0\) et \(\lim\limits_{x \to 0^+} x\ln x = 0\).
  • Concavité : \((\ln x)'' = -\dfrac{1}{x^2} < 0\) → courbe concave.
  • Équations : \(\ln(a) = \ln(b) \iff a = b\) ; \(\ln(x) = k \iff x = e^k\).
  • Application économique : utilité marginale décroissante, croissance ralentie, linéarisation des produits.
💡 Conseils pour le Bac :
  • Vérifie toujours le domaine de définition avant de résoudre une équation ou une inéquation avec \(\ln\).
  • N'oublie pas que \(\ln(a + b) \neq \ln(a) + \ln(b)\) : c'est l'erreur la plus fréquente.
  • Pour dériver \(\ln(u)\), utilise \(\dfrac{u'}{u}\) et vérifie que \(u > 0\).
  • Pour les limites, pense aux croissances comparées : \(\dfrac{\ln x}{x} \to 0\) en \(+\infty\).
  • La courbe de \(\ln\) est concave : elle est en dessous de ses tangentes.
  • En économie, une fonction d'utilité \(U(x) = \ln(x)\) traduit la loi de l'utilité marginale décroissante.
