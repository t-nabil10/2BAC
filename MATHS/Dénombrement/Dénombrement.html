Dénombrement 2ème Bac Sciences Économiques — Maroc

I. Principe fondamental du dénombrement

Principe multiplicatif : Si une expérience se déroule en \(k\) étapes successives, et que :
  • la 1ère étape a \(n_1\) issues possibles,
  • la 2ème étape a \(n_2\) issues possibles,
  • ...
  • la \(k\)-ème étape a \(n_k\) issues possibles,
alors le nombre total de résultats possibles est : \[ n_1 \times n_2 \times \cdots \times n_k \]
Pour compter, on multiplie les possibilités de chaque étape. C'est le principe de base de tout le dénombrement.
Exemple 1 : Un restaurant propose 3 entrées, 4 plats principaux et 2 desserts.
Combien de menus différents (entrée + plat + dessert) peut-on composer ?
On applique le principe multiplicatif : \(3 \times 4 \times 2 = 24\). 24 menus différents

II. Arrangements et permutations

1) Factorielle

Définition : Pour tout entier \(n \geq 1\), on appelle factorielle \(n\) et on note \(n!\) le produit : \[ n! = n \times (n-1) \times \cdots \times 2 \times 1 \] Par convention : \(0! = 1\).
\[ 1! = 1, \quad 2! = 2, \quad 3! = 6, \quad 4! = 24, \quad 5! = 120 \]

2) Arrangements

Définition : Un arrangement de \(k\) éléments parmi \(n\) (\(k \leq n\)) est une liste ordonnée de \(k\) éléments distincts choisis parmi \(n\).

Le nombre d'arrangements est : \[ A_n^k = \dfrac{n!}{(n-k)!} = n \times (n-1) \times \cdots \times (n-k+1) \]
L'ordre compte et les éléments ne se répètent pas. Exemple : le podium d'une course (1er, 2ème, 3ème).

3) Permutations

Définition : Une permutation de \(n\) éléments est un arrangement de \(n\) éléments parmi \(n\) (tous les éléments).

Le nombre de permutations est : \[ n! \]
On range tous les éléments dans un ordre donné. Exemple : classer 5 livres sur une étagère.
Exemple 2 : Dans une course de 10 chevaux, combien y a-t-il de podiums possibles (1er, 2ème, 3ème) ?
On choisit 3 chevaux parmi 10, dans l'ordre (le 1er, le 2ème, le 3ème). C'est un arrangement : \(A_{10}^3 = \dfrac{10!}{(10-3)!} = \dfrac{10!}{7!}\). \(A_{10}^3 = 10 \times 9 \times 8 = 720\). 720 podiums possibles
Exemple 3 : Combien de façons peut-on ranger 5 livres différents sur une étagère ?
On range les 5 livres, tous distincts, dans l'ordre : c'est une permutation. \(5! = 5 \times 4 \times 3 \times 2 \times 1 = 120\). 120 façons

III. Combinaisons

Définition : Une combinaison de \(k\) éléments parmi \(n\) (\(k \leq n\)) est un choix de \(k\) éléments distincts parmi \(n\), sans tenir compte de l'ordre.

Le nombre de combinaisons est : \[ C_n^k = \binom{n}{k} = \dfrac{n!}{k!(n-k)!} = \dfrac{A_n^k}{k!} \]
L'ordre ne compte pas. Exemple : choisir 3 joueurs dans une équipe de 11 pour former un comité.
💡 Propriétés des combinaisons :
  • \(\dbinom{n}{0} = \dbinom{n}{n} = 1\)
  • \(\dbinom{n}{1} = n\)
  • \(\dbinom{n}{k} = \dbinom{n}{n-k}\) (symétrie)
  • \(\dbinom{n}{k} = \dbinom{n-1}{k-1} + \dbinom{n-1}{k}\) (relation de Pascal)
Exemple 4 : Dans une classe de 20 élèves, combien de délégations de 3 élèves peut-on former ?
On choisit 3 élèves parmi 20, sans ordre : c'est une combinaison. \(\dbinom{20}{3} = \dfrac{20!}{3! \times 17!} = \dfrac{20 \times 19 \times 18}{3 \times 2 \times 1}\). \(= \dfrac{6840}{6} = 1140\). 1140 délégations possibles
Exemple 5 : Calculer \(\dbinom{5}{2} + \dbinom{5}{3}\).
\(\dbinom{5}{2} = \dfrac{5!}{2! \times 3!} = \dfrac{120}{2 \times 6} = \dfrac{120}{12} = 10\). \(\dbinom{5}{3} = \dfrac{5!}{3! \times 2!} = 10\) (symétrie : \(\dbinom{5}{3} = \dbinom{5}{2}\)). Donc \(\dbinom{5}{2} + \dbinom{5}{3} = 10 + 10 = 20\). Or \(\dbinom{6}{3} = 20\) : on retrouve la relation de Pascal \(\dbinom{6}{3} = \dbinom{5}{2} + \dbinom{5}{3}\). = 20

V. Méthode de résolution

  1. Lire attentivement l'énoncé et identifier ce que l'on compte.
  2. Se demander si l'ordre compte :
    • Oui → arrangement (ou permutation).
    • Non → combinaison.
  3. Se demander si les répétitions sont autorisées :
    • Oui → principe multiplicatif.
    • Non → arrangement ou combinaison.
  4. Appliquer la formule et calculer.
  5. Vérifier la cohérence du résultat (un nombre de choix est toujours entier positif).
💡 Pièges à éviter :
  • Confondre arrangement et combinaison (l'ordre compte ou non).
  • Oublier que \(0! = 1\).
  • Utiliser une combinaison quand l'ordre compte (ou inversement).
  • Ne pas vérifier que \(k \leq n\) dans \(A_n^k\) et \(C_n^k\).

VI. Applications économiques

Le dénombrement est utilisé en économie et en gestion pour :

  • Gestion des stocks : compter les combinaisons de produits.
  • Organisation du travail : répartir des employés sur des postes.
  • Marketing : compter les combinaisons d'offres promotionnelles.
  • Contrôle qualité : calculer le nombre d'échantillons possibles.
  • Analyse de risques : dénombrer les scénarios possibles.
Exemple 6 (application économique) : Une entreprise doit choisir 3 commerciaux parmi 8 pour former une équipe, et désigner un chef d'équipe parmi ces 3.
Combien de configurations différentes peut-elle former ?
1) On choisit d'abord 3 commerciaux parmi 8 (sans ordre) : \(\dbinom{8}{3} = \dfrac{8!}{3! \times 5!} = \dfrac{8 \times 7 \times 6}{3 \times 2 \times 1} = 56\). 2) Parmi ces 3, on désigne un chef (3 choix possibles). Total : \(56 \times 3 = 168\). 168 configurations possibles

Résumé général

  • Principe multiplicatif : on multiplie les possibilités de chaque étape.
  • Factorielle : \(n! = n \times (n-1) \times \cdots \times 1\), avec \(0! = 1\).
  • Arrangement : \(A_n^k = \dfrac{n!}{(n-k)!}\) → l'ordre compte, sans répétition.
  • Permutation : \(n!\) → on range tous les éléments.
  • Combinaison : \(\dbinom{n}{k} = \dfrac{n!}{k!(n-k)!}\) → l'ordre ne compte pas.
  • Propriétés : \(\dbinom{n}{k} = \dbinom{n}{n-k}\) et \(\dbinom{n}{k} = \dbinom{n-1}{k-1} + \dbinom{n-1}{k}\).
  • Application économique : gestion des stocks, organisation du travail, marketing, contrôle qualité.
💡 Conseils pour le Bac :
  • Avant de calculer, pose-toi toujours la question : « l'ordre compte-t-il ? »
  • Si l'ordre compte → arrangement (ou permutation). Sinon → combinaison.
  • N'oublie pas que \(0! = 1\) et que \(\dbinom{n}{0} = 1\).
  • Utilise la symétrie \(\dbinom{n}{k} = \dbinom{n}{n-k}\) pour simplifier les calculs.
  • Quand il y a plusieurs étapes, applique le principe multiplicatif.
  • Vérifie que le résultat est un entier positif et cohérent avec l'énoncé.
